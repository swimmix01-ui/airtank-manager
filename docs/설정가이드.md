# 공기통 관리시스템 v5.0 — 배포·보안 설정 가이드

반드시 **아래 순서대로** 진행하세요. 순서를 지키면 기존 데이터는 그대로 두고 앱이 끊기는 시간 없이 옮길 수 있습니다.

## 배포할 파일
| 파일 | 꼭 필요한가 | 역할 |
|---|---|---|
| `index.html` | 필수 | 앱 본체 |
| `sw.js` | 강력 권장 | 안드로이드 알림, 오프라인 실행, 빠른 시작 |
| `manifest.webmanifest`, `icon-192.png`, `icon-512.png` | 권장 | 홈 화면에 앱처럼 설치 |
| `firestore.rules` | 배포하지 않음 | Firebase 콘솔에 붙여넣을 보안 규칙 |

다섯 파일을 **같은 폴더**에 올리세요 (Netlify/GitHub Pages 등). 카메라 스캔과 알림은 **HTTPS 주소**에서만 동작합니다.

---

## 1단계. 로그인 계정 만들기 (Firebase 콘솔)
1. https://console.firebase.google.com → 프로젝트 **airssat**
2. **Authentication → 시작하기 → Sign-in method → 이메일/비밀번호 → 사용 설정 → 저장**
3. **Users → 사용자 추가**: 구조대 공용 계정을 아래 값으로 **정확히** 만듭니다.
   - 이메일: `rescue.pohang@airssat.app` (실제 메일함은 필요 없습니다. 로그인할 때 입력하지 않고 앱에 미리 넣어둔 값입니다)
   - 비밀번호: 구조대에서 쓸 비밀번호 **8자 이상** ← 대원들은 앱에서 이것만 입력합니다
   - 다른 이메일을 쓰려면 `index.html`의 `sharedEmail`과 `firestore.rules`의 이메일을 둘 다 바꾸세요.
4. (권장) **Authentication → 설정 → 사용자 작업**에 "가입 허용(Enable create/sign-up)" 항목이 있으면 끄세요. 이 항목이 없더라도 3단계의 허용 목록 규칙이 임의 가입을 막아줍니다.

## 2단계. 새 index.html 배포
- 새 파일들을 올리고, 1단계에서 정한 비밀번호로 로그인되는지, 기존 탱크·기록이 그대로 보이는지 확인하세요.
- 이 단계까지는 예전 보안 규칙(전체 공개)이 그대로라서, 예전 버전 앱도 아직 동작합니다.

## 3단계. 보안 규칙 적용 ← 실제로 데이터가 보호되는 단계
1. `firestore.rules`에는 공용 계정 이메일이 이미 들어 있습니다 (이메일을 바꾸지 않았다면 그대로 사용).
2. Firebase 콘솔 → **Firestore Database → 규칙** 탭 → 기존 내용을 전부 지우고 붙여넣기 → **게시**
3. 확인할 것:
   - 새 앱: 정상 동작해야 합니다.
   - 예전 앱 또는 로그인하지 않은 접근: "권한 없음"이 떠야 합니다 ← 이게 정상입니다.
   - ⚠️ 예전 버전 `index.html`이 남아 있는 기기는 모두 새 버전으로 바꾸세요.

## 4단계. API 키 사용처 제한 (권장)
Google Cloud 콘솔 → **API 및 서비스 → 사용자 인증 정보** → "Browser key (auto created by Firebase)":
- **애플리케이션 제한사항: HTTP 리퍼러** → 앱을 배포한 주소 추가 (예: `https://내사이트.netlify.app/*`)
- **API 제한사항**: Identity Toolkit API, Token Service API, Cloud Firestore API

## 운영 참고
- **비밀번호 변경**: 앱의 설정 → 비밀번호 변경. 변경하면 다른 대원 폰은 다음에 새 비밀번호로 다시 로그인해야 합니다. 대원이 전출하거나 비밀번호가 외부로 새어나갔다면 바꿔주세요. 비밀번호를 잊었을 때는 콘솔 → Authentication → Users에서 재설정합니다.
- **동기화**: 저장은 즉시 서버에 반영됩니다. 다른 기기의 변경은 탱크 상태 5분, 전체 데이터 30분마다, 그리고 앱으로 돌아왔을 때 자동으로 반영됩니다. 상단의 동기화 표시를 누르면 바로 동기화됩니다.
- **오프라인**: 마지막으로 받은 데이터는 볼 수 있지만, 저장은 연결된 뒤에만 됩니다.
- **알림**: 앱을 열거나 동기화될 때 하루 한 번만 알립니다. 앱이 완전히 꺼져 있을 때 오는 서버 푸시(FCM)는 서버 구성이 별도로 필요해서 이번 버전에는 넣지 않았습니다.
- **Firebase 무료 사용량**: 하루 읽기 5만 건까지 무료입니다. 이 앱은 전체 동기화 1번에 문서 수만큼 읽기를 사용합니다 (예: 탱크 100개와 충전 기록 2,000건이면 약 2,100건).

## 데이터 변경사항 (기존 데이터와 호환)
기존 필드는 모두 그대로 읽습니다. 새로 추가된 필드는 다음과 같습니다.
- 탱크: `mfgDate`(제조연월), `inspCycle`(검사주기 지정), `lifeYears`(사용수명), `inspFailed`(불합격·사용금지), `updatedAt`, `updatedBy`
- 충전기록: `createdBy`
- `config/settings` 문서: 관서명·관리 기준을 모든 기기가 공유
